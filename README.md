# my cloth simulation

## 启动

1. 使用 Visual Studio 打开 `My_Cloth_Simulation.sln`。
2. 选择 `x64` 配置并生成解决方案。
3. 运行项目。

## 操作方法

| 操作 | 按键 |
| --- | --- |
| 平移布料 | `W` / `A` / `S` / `D` |
| 升高 / 降低布料 | 左 `Shift` / 左 `Ctrl` |
| 顺时针 / 逆时针旋转布料 | `Q` / `E` |
| 调整风力方向 | 方向键、右 `Shift`、右 `Ctrl` |
| 旋转视角 | 按住鼠标左键并拖动 |
| 缩放视角 | 按住鼠标右键并左右拖动 |
| 重置视角 | `R` |
| 暂停 / 继续模拟 | `Space` |
| 释放 / 固定布料 | `Backspace` |
| 切换面 / 线框显示 | `P` |
| 开启 / 关闭背面剔除 | `C` |
| 退出程序 | `Esc` |
